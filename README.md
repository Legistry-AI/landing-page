# Legistry AI - Landing Page

AI-powered legal operations platform for modern legal teams.

## Features

- 📄 **Contract Agent** - Draft contracts in 60 seconds with AI
- ✅ **Compliance Agent** - Real-time regulatory monitoring
- 🤝 **Vendor Agent** - Streamline vendor onboarding
- 📊 **Analytics Agent** - Predictive legal spend analytics
- 🤖 **AI Document Assistant** - Chat with your legal documents

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Lucide React Icons

## Development

```bash
npm install
npm run dev
```

## Deployment

This project is ready for deployment on Vercel:

```bash
npm run build
```
